# B-roll provider routing

| Need | Preferred route | External candidate | Guardrail |
| --- | --- | --- | --- |
| filing, chart, product UI, real event | sourced evidence | none | preserve source and citation |
| editorial paper collage | internal HTML/HyperFrames | Vox Director | label generated elements; verify licenses |
| cinematic cutaway or sticker animation | internal motion asset | seedance2 | no factual impersonation |
| recurring conceptual character | dasheng-lemon-illustrations | none | keep channel visual identity |
| title, number, diagram, transition | Remotion/HyperFrames | none | build data-native animation |

External candidates are registered in `configs/video/upstream_video_skills.json`. They are optional and are not installed or updated by this skill.
