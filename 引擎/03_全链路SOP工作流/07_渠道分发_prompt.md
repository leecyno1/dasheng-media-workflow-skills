# 07 发布 Prompt（旧兼容）

> 当前正式主链已拆成 `transwrite -> publish`。转写生产请使用 `skills/dasheng-stage-transwrite/SKILL.md`，发布执行请使用 `skills/dasheng-stage-publish/SKILL.md`。本文件仅保留历史参考。

## 阶段目标

围绕同一选题的已确认正文底稿与发布决策，形成最终发布包并安排发布顺序。

## 适用输入

- `transwrite_manifest.json`
- `publish_decision.json`
- 标题池
- 摘要
- 图表/图片链接
- 按需素材回填说明
- 渠道偏好

## 输出要求

1. 发布主包
2. 各渠道发布成品
3. 发布时间计划
4. 发布检查清单
5. 人工干预位

## Prompt

```text
你现在负责自媒体创作 SOP 的第 5 阶段：发布执行。

请基于同一选题的确认正文、目标渠道和按需素材结果，生成最终可执行的发布包。

你必须遵守：
1. 核心判断不能变。
2. 不同渠道的节奏、标题、首屏和 CTA 要单独优化。
3. 不要简单复制粘贴全文，要体现渠道消费差异。
4. 所有图片、图表、链接尽量保留为可点击形式。
5. 发布阶段不再反向重写正文，只做发布适配与编排。
6. 视频、播客、封面生产已前移到 Transwrite；本阶段只验收状态并打包。

请按以下结构输出：

一、发布主包
- 主标题：
- 备用标题：
- 发布主文案：
- 主图/图表清单：
- 主链接占位：

二、公众号发布包
- 标题 3-5 个
- 导语
- 封面文案
- 正文版本说明
- 文末 CTA

三、小红书图文发布包
- 标题 2 套
- 封面文案
- 页卡结构
- 标签
- 评论区引导

四、视频号 / 抖音口播包
- 口播标题
- 3 秒 Hook
- 60-120 秒口播稿
- 分镜建议
- 结尾 CTA

五、社群/朋友圈转发包
- 40-80 字摘要
- 引导问题
- 附带链接/图片建议

六、发布计划
- 先发哪个渠道
- 各渠道建议发布时间
- 哪些内容可以二次剪裁复用

七、发布检查清单
- 链接是否可点击：
- 图片是否齐全：
- 标题是否定稿：
- 风险提示是否保留：

八、人工干预位
- 建议人工最后确认的部分：
- 发布前允许人工替换的标题/封面：
- 发布后需要立即记录的观察点：

当前输入材料如下：
<粘贴终稿和分发要求>
```

## 完成检查

- 是否完成四类渠道成品
- 是否体现渠道差异而不是同文复用
- 是否给出发布时间建议
- 是否为人工发布前复核预留了明确入口
